**What is this about?**
An application designed with security in mind.

**Tools and technologies:**

**Frontend**
Vanilla js
vanilla css

Why? To not automate security issues, and handle them manually like a real person

**Backend**
Node + Express js

**Database**
Postgres + Prisma ORM


----

**Features**

Users can sign up, login, access a dashboard, browse through artworks, leave a comment on specific artworks, edit their profile.
Admin can login, access the dashboard, delete users, delete artworks, leave a comment on specific artworks, see API documentation.
